# 🧮 Calculadora JavaScript

Projeto de uma calculadora web desenvolvida utilizando **HTML, CSS e JavaScript**.

O projeto foi desenvolvido como parte dos meus estudos em desenvolvimento web, com o objetivo de praticar conceitos fundamentais de **HTML, CSS e JavaScript**, além da manipulação do DOM e criação de eventos.

## 🚀 Funcionalidades

* Adição
* Subtração
* Multiplicação
* Divisão
* Números decimais
* Limpeza do visor
* Exibição do resultado
* Interface responsiva
* Interação através de botões

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📂 Estrutura do projeto

```text
calculadora-js/
├── index.html
├── style.css
├── script.js
└── README.md
```
